# Hi, I'm Daniel 👋

Computer Science student in Brazil, building toward a career in **robotics software**. I design robots end to end, from fabrication-ready code CAD to ROS 2 simulation, and I check every result against a datasheet, a hand calculation or the CAD itself before I call it done.

Open to robotics roles in Brazil and abroad.

## Focus

- **ROS 2** manipulation and mobile robots: MoveIt 2, ros2_control, Gazebo
- **Code CAD** (CadQuery): one parametric model for simulation *and* 3D printing, with ISO hardware and datasheet hole patterns
- **Verification**: every pipeline stage has an automatic check against an independent reference

## Projects

### [4-DOF robot arm with MoveIt 2](https://github.com/Danion1/robot-arm-moveit2)

<a href="https://github.com/Danion1/robot-arm-moveit2"><img src="https://raw.githubusercontent.com/Danion1/robot-arm-moveit2/main/midia/demo.gif" alt="Simulated pick and place: the arm picks a 20 mm cube in Gazebo and places it on the other side" width="480"></a>

Serial arm with a rack-and-pinion gripper, designed for PLA printing around DYNAMIXEL servos and simulated end to end: CadQuery → URDF → Gazebo + ros2_control → MoveIt 2 → pick and place with grasp verification. Kinematics, joint torques and MoveIt 2 collision checking are validated against the CAD. *Simulated only, not built yet.*
