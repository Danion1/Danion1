### Hey there! 👋

I'm **Daniel**, a Computer Science student in Brazil who designs and builds machines from scratch.

I take projects from the first idea to a system that works: the calculations, the CAD, the electronics, the code and the simulation that proves it.

Robots are where I started. Drones, motors and rockets are next.

Hardware costs money, so my machines live in simulation for now, but every part is designed to be built for real.

My favorite project so far is my [**robot arm**](https://github.com/Danion1/robot-arm-moveit2): printable parts, ROS 2 and a simulated pick and place.
